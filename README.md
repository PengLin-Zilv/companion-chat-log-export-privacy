# Companion Chat Log Export Privacy Policy

Public privacy-policy documents for LinkLab's Companion Chat Log Export.
This repository does not contain extension source code, credentials, or chat logs.

## Policy

The policy is maintained in [index.md](index.md).

After GitHub Pages is enabled, the policy URL will be:
https://PengLin-Zilv.github.io/companion-chat-log-export-privacy/

## Publishing

In repository Settings > Pages, select **Deploy from a branch**, then
**main** and **/(root)**. Save and check the Pages deployment before using
the URL in the Chrome Web Store.

Review policy changes with the publisher before pushing to `main`.
Once Pages is enabled, updates to that branch are published automatically.
